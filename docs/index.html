§1 · principle of operationprincipio de operación

    
From raw traffic to an actionable alert, in one pass.Del tráfico en bruto a la alerta accionable, en una pasada.

    

      
capture →A lightweight agent taps the interface, or you feed it a PCAP.Un agente ligero captura la interfaz, o le pasas un PCAP.

      
featurize14 flow features per flow, in real time.14 features por flujo, en tiempo real.

      
scoreThe VAE detects what nobody has seen; the quantum-kernel SVM separates threat from noise.El VAE detecta lo que nadie ha visto; la SVM con kernel cuántico separa amenaza de ruido.

      
threshold →One continuous anomaly score per flow. You set where normal ends.Un score continuo por flujo. Tú decides dónde acaba lo normal.

      
postfilter →Silences broadcast and discovery noise (SSDP, mDNS, DNS chit-chat) before you see an alert.Silencia ruido de difusión y descubrimiento (SSDP, mDNS, DNS) antes de que veas una alerta.

      
alertTelegram notification, hub console, REST. Self-hosted end to end.Telegram, consola hub, REST. Autoalojado de principio a fin.

§2 · honest numbersnúmeros honestos

    
F1 0.711 / 0.707

    
QSVM vs classical svm_linear on our 5 labeled PCAPs, 2026-10-14, CV=1. The quantum kernel is not magically better, and this page will not pretend it is. The argument is elsewhere: no signatures, unsupervised, the score exists before the name.QSVM frente a svm_linear clásico en nuestros 5 PCAP etiquetados, 2026-10-14, CV=1. El kernel cuántico no es mágicamente mejor, y esta página no va a fingir que lo es. El argumento está en otro lado: sin firmas, sin supervisión, el score existe antes que el nombre.

    
100.0%

    
Yes, the candidate model flags the normal.pcap at 100% too. It is a retraining candidate, and that is why this page shows raw scores and a threshold you control, never a friendly green "all clear".Sí, el candidato también marca el normal.pcap al 100 %. Es un candidato en reentrenamiento, y por eso esta página muestra scores crudos y un umbral que controlas, nunca un verde "todo despejado" de cortesía.

§4 · install, and it answers backinstálalo, y responde

    
Click a command to run it in the console on this page. The answer is recorded stdout from a real machine, not a mockup.Pulsa un comando para ejecutarlo en la consola de esta página. La respuesta es stdout grabado en una máquina real, no un simulacro.

$ pip install -e ".[all]"
$ qzero analyze suspicious.pcap --model-dir models/qzero-candidate
$ qzero server --port 8000   # hub + REST + console
